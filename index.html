CBS-ERM

A Data-Driven Energy Resource Management System for Utilizing CBS Backup Power Toward Smart City Resilience

AIoT Smart Energy Edge-Cloud Architecture Deep Reinforcement Learning MQTT / Modbus
🧭

Project Vision

This system takes a proactive approach to utilizing and redesigning the backup power systems of Cellular Base Stations (CBSs) — transforming them into distributed, intelligent energy hubs that support power resilience in smart cities. The architecture integrates real-time sensing, cloud intelligence, and AI-driven decision-making to optimize energy usage, detect anomalies, and dispatch backup power intelligently across critical infrastructures.

🔄

What We Need vs What We Provide

A simple, one-input agreement: operators share power consumption data, and the system delivers a full intelligent energy management suite in return.

🤝 What We Need from CBS Operators

Only one key input is required to enable everything:

  • 📊 Power Log Data — Total electrical power consumption from each CBS tower, acquired automatically through the deployed ISC (Intelligent Sensor & Control) unit. No additional sensors, manual reporting, or operator overhead required.

🎁 What We Provide in Return

  • 🧠 AI-Based Optimization — Load shifting during peak hours, smart scheduling, battery charge/discharge planning, and tower-tailored energy savings.
  • 📡 Real-Time Monitoring — Live dashboards of power usage, anomalies, and device health, plus historical analytics & trend reports.
  • 🔄 Remote Control & Automation — Secure dispatch of control signals to ISC units via MQTT/Modbus; automated toggling of loads, battery modes, and generators.
  • 🔋 Extra Power Sharing — When excess energy is detected, intelligently share with neighboring CBSs or critical infrastructures (hospitals, emergency shelters) — boosting resilience and sustainability.
🏗️

System Architecture

A five-layer architecture that flows from edge sensors at CBS towers through a secure broker, into cloud and ML services, and back out as intelligent control signals.

⚙️

Core Modules & Components

A breakdown of each module's role, responsibilities, and underlying technology.

01

⚡ Intelligent Sensor & Control (ISC)

The ISC unit acts as the intelligent edge layer responsible for local energy control in cellular base stations. Hardware is installed inside the CBS power cabinet with real-time monitoring modules.

  • 🧠 Monitoring — Reads real-time power-related data such as voltage, current, and power consumption.
  • 🔄 Optimization — Applies on-device logic for local energy efficiency and load balancing.
  • 🌐 Communication — Sends and receives data and control signals via MQTT or Modbus protocols to/from the cloud.

These functions enable distributed energy regulation for improved resilience across CBS networks.

02

🔐 Secure Broker Layer (MQTT Communication Backbone)

The Secure Broker Layer serves as the middleware for efficient and encrypted data flow between ISC devices and the cloud backend. Clients connect to the centralized MQTT broker (Centralized-AIoT@mqtts://) with TLS support.

  • 🧩 Protocol — Built using the lightweight MQTT protocol for scalable, publish-subscribe messaging.
  • 🔐 Security — Uses Mosquitto broker with built-in TLS encryption to ensure data confidentiality and broker authentication.
  • 🔄 Integration — Seamlessly connects edge devices (ISC) with cloud services (e.g., Node-RED, ML backend) for real-time data exchange and control signal routing.

Enables low-latency, secure, and scalable communication architecture essential for distributed energy regulation.

03

☁️ Cloud Operations

  • Processes incoming data streams in real time.
  • Implements clustering, pre-processing, and decision analytics.
  • Built using Node.js, Express, and PostgreSQL.
04

🧠 Machine Learning Ops

  • Anomaly Detection — Regression-based models for early warning.
  • Predictive Analysis — Multi-layer stacked deep learning models for load forecasting.
  • Optimization — AI-based decision-making using Deep Reinforcement Learning (DRL) or LLMs to schedule and dispatch backup power.
05

📤 Control Signal Dispatch

  • Cloud sends intelligent control signals back to edge ISC units.
  • Uses MQTT or Modbus for signal communication.
  • Enables closed-loop, automated energy management.
06

📊 Frontend Dashboard

Developed using React. The admin panel includes:

  • Real-time monitoring of CBS energy data.
  • Visualization of detected anomalies.
  • Predictive alerts and control logs.
07

🔌 RESTful API Layer

Backend exposes endpoints for:

  • Data upload from ISC units.
  • Control commands.
  • Visualization queries for the dashboard.
